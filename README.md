# HUNTR/X: Demons Fall

A Phaser 3 + Vite mobile-first action-platformer prototype.

## Current development focus

Level 1-1 is temporarily running as a short vertical slice so the next passes can focus on Rumi and the Seoul rooftop art direction:

- Rumi remains the primary character for polish
- Five active rooftop platforms
- Four Stalker enemies for repeatable combat testing
- Brute, Wraith, boss, powerups and longer-level content remain in the codebase but are parked for now
- Existing mobile controls, combat, animation and visual-polish systems remain active

## Parked prototype systems

- Three selectable hunters with distinct combat profiles
- Enemy variants and Dread Captain boss
- Sync/support/duo/full-sync mechanics
- Run upgrades and checkpoint recovery
- Standalone transparent Rumi pose assets for idle, run, jump, attacks, finisher, aerial and dodge
