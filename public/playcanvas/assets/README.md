# PlayCanvas prototype assets

Place the mobile-optimised Rumi GLB here using exactly this filename:

`rumi.glb`

The prototype intentionally falls back to a simple purple capsule if the model is absent, so the arena and controls can still be tested.

Source model attribution retained from the supplied GLB:
- Creator: Guilherme Navarro
- Licence embedded in source file: CC BY 4.0

For this prototype, the supplied source GLB has been texture-downscaled for mobile testing while retaining its mesh and rig.
